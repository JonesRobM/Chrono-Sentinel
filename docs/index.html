What the model is looking at

The window is z-scored before the transformer sees it, which discards level and scale. These ten statistics carry that information back in through a separate branch. Values are shown after scaling by the training-split statistics, so 0 means "typical of training data".

FeatureRawScaled

The same forward pass runs three ways: PyTorch for training, numpy in the container, and this JavaScript port. All three are held to the same numbers by parity tests — see What doesn't work for where the model falls short, including the fact that this uncertainty interval does not reliably identify errors.
